# Purchases Module Documentation

## Procurement Processes Overview
- **Description**: The purchases module manages all aspects of the procurement process, from order creation to receiving goods.
- **Key Features**:
  - Purchase Orders: Create and manage purchase orders.
  - Vendor Management: Maintain vendor information and track interactions.
  - Receiving Goods: Track received goods and update inventory.

## Workflows
- **Purchase Order Workflow**:
  1. Create purchase order.
  2. Allocate budget.
  3. Receive goods.

- **Vendor Management Workflow**:
  1. Add new vendor.
  2. Update vendor details.
  3. Track vendor interactions.

- **Receiving Goods Workflow**:
  1. Receive goods from purchase order.
  2. Update inventory levels.
  3. Generate receiving reports.
